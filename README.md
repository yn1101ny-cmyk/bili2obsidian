# MyNoteApp

本地优先的「视频 → 可理解笔记」工具。

把哔哩哔哩视频链接丢进来，应用自动提取视频里的内容（字幕 / 语音转写），
整理成结构化笔记，并补充必要的背景知识与上下文，让碎片化的知识在更短的时间里被真正理解。

## 目标

- **输入**：一个 B 站视频链接（BV 号 / av 号 / 完整 URL / 合集）
- **输出**：一份结构化、可检索、可复习的笔记
  - 大纲与时间戳（可跳回原视频核对）
  - 核心论点与结论
  - 关键概念解释（面向「没看过视频的人也能看懂」）
  - 补充背景：前置知识、易混淆点、延伸阅读
  - 疑问与待验证项（标注哪些是视频原话、哪些是补充推断）
- **体验**：尽量减少手工整理时间，把「看视频」变成「读笔记 + 回看重点」

## 数据安全原则（硬性约束）

1. **本地优先**：笔记、转写文本、缓存全部保存在本机，默认不上传任何服务器。
2. **不窃取数据**：不采集与功能无关的信息，不内置遥测、埋点、后台上报。
3. **密钥不入库**：`.env`、Cookie、API Key 一律由 `.gitignore` 排除，仓库中只保留 `.env.example`。
4. **可审计**：所有对外网络请求集中在明确的适配器模块内，便于逐条核查。
5. **可删除**：用户数据集中存放，提供一键清除本地数据的路径。
6. **来源可追溯**：笔记中区分「视频原文」与「模型补充」，避免把推断当成事实。

> 违反以上任一条的功能，一律不实现，除非用户明确要求。
