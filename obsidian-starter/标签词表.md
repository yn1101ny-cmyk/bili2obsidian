# 标签词表

标签一多就没人用了。这里是一套够小、能落地的规矩 —— 是**建议**，不是插件要求。

## 规矩

1. **一篇笔记 1~3 个主题标签**，说清「这篇属于什么领域」。
2. **类型标签不占名额**：`视频笔记`、`播客`、`人物`、`工具` 这类说明「它是什么形态」的，
   生成器会自动加，不要因为标签数量超了就把它们删掉。
3. **只标类型和领域，不标态度**。`重要`、`收藏`、`待读`、`好文` 请用插件标记或文件夹 + 查询代替 ——
   它们会随着时间失去意义。
4. **新标签先登记再用**：想加就先写进这张表，同一类攒到 3~5 篇再考虑合并（例如先 `模型`、`手办`，
   够了再合成 `模型`）。
5. **别造近义词**：已经用了 `装机`，就不要再出现 `攒机` `硬件配置`。

## 生成器自动加的标签

| 标签 | 含义 |
| --- | --- |
| `视频笔记` | 这个工具生成的笔记，方便一键筛出来 |
| `bilibili` | 来源站点 |

## 主题标签示例

| 标签 | 适用范围 | 什么时候合并 |
| --- | --- | --- |
| `AI/用法` | 怎么用 AI 干活（提示词、工作流、工具链） | `AI/模型`、`AI/用法` 各自攒够 5 篇再分不动 |
| `科普` | 面向大众讲原理 | — |
| `认知` | 思维、决策、方法论 | — |
| `装机` | 电脑硬件与配置单 | 与 `数码` 合并 |
| `理财` | 投资、宏观、个人财务 | 与 `经济学` 分不清时合并 |
| `模型` | 拼装模型、手办 | 与 `手办` 合并 |
