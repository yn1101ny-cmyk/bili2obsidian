# 库的约定（给 AI 客户端看）

> 如果你用 Claude Code / DSH 这类客户端**直接在库里读写笔记**，把这份文件放在库根，
> 大多数客户端会自动读它。不用 AI 客户端的话，这个文件可以删。

## 写之前

1. **先读再写**：写一篇新笔记前，先搜一遍库里有没有同主题的笔记。有就补进去，不要新建平行的一篇。
2. **落点看内容**：按主题文件夹归档（`视频笔记/`、`AI/`、`理财/`…）。拿不准就放进收件箱文件夹，别硬猜。
3. **不确定就问**：宁可问一句「这篇你想解决什么问题」，也不要按自己的猜测写一大堆。

## 笔记怎么写

- 文件名是**一句完整的话**（这篇笔记的主张），不要用「某某视频笔记」这种名字；不要放日期、BV 号。
- 每篇必须有 frontmatter，字段见 `视频笔记模板.md`；`tags` 用 `标签词表.md` 里的词。
- 时间戳一律写成标准 Markdown 链接：`[03:20](https://www.bilibili.com/video/BVxxx?t=200)`，
  这样 Obsidian 里能点、别的编辑器里也读得懂。**不要**自己编 `?t=0`。
- **区分来源**：
  - `✅` 开头 = 视频里的原话（可以去掉口癖，但不能改意思）；
  - 没有标记的结论 = 转写之外的补充，必须能在画面文字或转写原文里找到依据；
  - 找不到依据的，写进「❓ 存疑与待验证」，只提问题，不要给答案。
- 转写和 OCR 都可能出错（同音字、专有名词、画面识别）。识别错误明显时，在笔记里说明「以图/以原文为准」。

## 不要动

- `.obsidian/`、`.git/`、`.trash/`；
- 别人已有的笔记（除非本次任务就是改它）；
- 提交 `data.json` 一类含密钥的插件配置。

## 素材

- 一篇视频的素材放在 `附件/转写/<BV号>/`：`转写原文.txt`、`画面文字.txt`、`元数据.json`、`shots/`（关键截图）。
- 笔记里引用截图用 `![[附件/转写/<BV号>/shots/xxx.jpg|560]]`，每张图下面写一句它是什么。
