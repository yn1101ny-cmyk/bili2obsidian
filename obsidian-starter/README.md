# 在 Obsidian 里用：起步文件夹

这里 4 个文件是**可选的**，用来把这个工具的产出「接上」你的库，让笔记不只是躺在文件夹里，
而是能被查询、能顺着主题找到。

把 4 个文件复制到你 Obsidian 库的根目录（或任意文件夹）即可，没有依赖关系：

| 文件 | 干什么 | 需要插件吗 |
| --- | --- | --- |
| `首页.md` | 仪表盘：最近生成的笔记、按主题分组、缺少 `goal` 的、孤立笔记 | 需要 [Dataview](https://github.com/blacksmithgu/obsidian-dataview) |
| `视频笔记模板.md` | 新建笔记时的骨架（Templater / 手动复制都行） | 不需要 |
| `标签词表.md` | 自己定一套标签规矩，避免越用越乱 | 不需要 |
| `AGENTS.md` | 如果你也用 AI 客户端（Claude / DSH 等）写库，给它一份约定 | 不需要 |

> 完整的接入方式（`DATA_DIR` 怎么指、只把 `notes` 链接进库、常见坑）见
> 项目里的 [docs/OBSIDIAN.md](../docs/OBSIDIAN.md)。

## 假设的目录结构

这几个文件默认你的库里是这样：

```
你的库/
├─ 首页.md                ← 从这个文件复制过去
├─ 视频笔记/              ← 笔记放这里（MyNoteApp 的 notes 目录链接/放进来）
│   ├─ 某某视频讲了什么.md
│   └─ ...
└─ 附件/                  ← 截图、转写稿
    └─ 转写/BVxxxxxxxxx/
```

文件夹名不一样没关系，改 `首页.md` 里 Dataview 的 `FROM "视频笔记"` 那一行就行。

## 一分钟接上

1. 复制 4 个文件进库；
2. 装 Dataview 插件（设置 → 第三方插件 → 浏览 → Dataview）；
3. 打开 `首页.md`，如果表格是空的，把它上面 `FROM "视频笔记"` 改成你实际的笔记文件夹名。
