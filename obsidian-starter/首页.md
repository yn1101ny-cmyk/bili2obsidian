# 首页

> 这个文件靠 [Dataview](https://github.com/blacksmithgu/obsidian-dataview) 插件活着。
> 把两个 `FROM "视频笔记"` 改成你实际的笔记文件夹名（下面第一块和第三块）。

## 最近生成的笔记

```dataview
TABLE WITHOUT ID
  file.link AS 笔记, up AS UP主, dateformat(date(created), "MM-dd") AS 生成
FROM "视频笔记"
WHERE created
SORT date(created) DESC
LIMIT 20
```

## 按 UP 主分组

```dataview
TABLE WITHOUT ID
  rows.file.link AS 笔记, length(rows) AS 篇数
FROM "视频笔记"
GROUP BY up
SORT length(rows) DESC
```

## 还没写「读完能做到」（缺 goal 的笔记）

生成器写 `goal` 用的是它自己的理解；空白的这几篇值得你自己补一句。

```dataview
LIST
FROM "视频笔记"
WHERE !goal OR goal = ""
```

## 孤立笔记（没有任何链接进出）

孤立不等于没用，但通常意味着它还缺一条「和我的知识连起来」的路。

```dataview
LIST
FROM "视频笔记"
WHERE length(file.inlinks) = 0 AND length(file.outlinks) = 0
SORT file.ctime DESC
```
